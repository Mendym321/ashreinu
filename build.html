Ashreinu → Supabase indexer

Scans event IDs 1–14000 and writes each one into your Supabase table. Safe to run more than once — it overwrites existing rows rather than duplicating.

Find & Fill Gaps

The scan above hit heavy rate-limiting from Ashreinu's live API — any ID that got rate-limited was silently skipped and never saved. This finds exactly which IDs (out of 1–14000) are missing from our own database, then re-fetches only those — much smaller and gentler than a full re-scan.
